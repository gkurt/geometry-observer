geometry-observer

The layout engine tells you when an element moved or resized. No polling, no requestAnimationFrame loop, and no main-thread work at all while nothing changes.

A node graph

Drag a node, or resize it by its corner. Nodes shove each other aside so no two ever overlap, and the edges stay attached through the whole cascade. Hover one for a tooltip, or click to pin it open and hover another. They ride in the top layer, so they spill past the edge of the scene instead of being clipped by it. Every rect behind all of this arrives in a callback, and when the graph is still nothing runs at all.

The middle rows are the point: “a sibling above me grew, so I moved” is the most common way an element changes position, and no other observer reports it.

Honest about the cost

A probe is a real box, so it adds time to every reflow, even ones where nothing it watches moved. A sampler instead pays on every frame, moving or not. The two meet at a low single-digit number of reflows per second, which makes this an idle-cost and coverage win, not a throughput win.

How it works

anchor() and anchor-size() resolve a target's box into computed lengths on a hidden probe. Computed lengths transition. A running transition dispatches a DOM event. That's the whole trick. 

/* the probe: a top-layer element mirroring #target's box */
#probe {
  position: fixed;
  position-anchor: --target;
  top: anchor(top);   left:   anchor(left);
  width: anchor-size(width); height: anchor-size(height);
  transition: top 1ms, left 1ms, width 1ms, height 1ms;  /* the tap */
}
